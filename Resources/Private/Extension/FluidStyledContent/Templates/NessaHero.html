A single hero item is rendered as a static hero (no carousel markup, no controls, no indicators). More than one item renders a Bootstrap carousel. {heros -> f:count()}
No prev/next arrow controls: the indicators (direct, keyboard-focusable navigation), Bootstrap keyboard arrows, touch swipe and the pause control cover navigation accessibly. See CeHero.js. Pause/play control for the auto-rotating carousel (WCAG 2.2.2); wired in CeHero.js.
