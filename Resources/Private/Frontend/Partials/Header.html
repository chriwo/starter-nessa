Header position behaviour is configured via the site setting starter.header.position (sticky|fixed) and exposed as settings.header.position. It is reflected as the state class is-header-sticky / is-header-fixed so the SCSS can target each mode without JavaScript. {f:if(condition: '{settings.header.position} == \'fixed\'', then: 'fixed', else: 'sticky')} In fixed mode the header is detached from the flow, so the configured offset (starter.header.fixedOffset) reserves space below it for the first content. In sticky mode no offset is needed — the header stays in the document flow.
